Percy External API

Read the data of the brokerages your credential covers, as JSON over HTTPS. Every API on this site shares the same authentication, limits and error format, described on this page.

  • Base URL · https://api.getbuyside.com/v1
  • 100,000 requests / month per key
  • 29 s max per request
1 · AuthenticateClient credentials and API key are checked.
2 · ScopeResults are limited to your brokerages; filters only narrow them.
3 · RespondJSON with the data, or an error with its cause.

Available APIs

  • Buyer ProfilesThe buyer profiles (My Buyers) of your brokerages: a paginated list and the full detail of each buyer. /buyers/profiles

Authentication

Every request sends two headers: your client credentials in Authorization and your API key in x-api-key. Both are delivered to you through a secure channel, never by email or chat.

ItemValue
Base URLhttps://api.getbuyside.com/v1
AuthorizationBasic <base64 of client_id:client_secret>
x-api-keyYour API key
ScopeThe brokerages and the routes assigned to your credential. Each API page says which routes it covers.
Every request
curl -s "https://api.getbuyside.com/v1/<route>" \
  -H "Authorization: Basic $(printf '%s' "$CLIENT_ID:$CLIENT_SECRET" | base64)" \
  -H "x-api-key: $API_KEY"

Keep the client secret and API key on your servers. Do not embed them in a browser or mobile app, and tell us right away if you think they were exposed so we can rotate them.

Errors and limits

Errors return JSON with a Message that explains the cause. Each API page lists the cases specific to its routes.

StatusWhen
400A parameter is invalid: wrong type, out of range or not allowed with another one.
401 / 403Missing or invalid credentials or API key, or a route your credential does not cover.
404The record does not exist or is outside your scope.
429Too many requests, or the monthly quota is used up.
504The request took longer than 29 seconds.

Quota. Each API key allows up to 100,000 requests per month across all routes. Contact us if you expect more.

Support

For questions, a new credential, more quota or a suspected exposure of your keys, contact your Percy account team. Include the time of the request (UTC), the endpoint and the HTTP status. Never send the client secret or the API key.
